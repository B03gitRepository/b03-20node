# 四组协作入口

从[四组接口、脱敏样例和本地自测](../collab/README.md)进入本组工作。第一次联调按[仓库首页](../README.md)设置官方场景包，默认使用仓内锁定的分组引擎。系统集成组负责 OM/RC、A2A、权限、设备写入和双规格核验。

**提交给系统集成组的内容**包括组件版本、配置差异、复现命令和一张对照表。表中写明原工单与新方案的动作、U/W、耗时、设备生效和读回数。样本少时写出样本数，未确认的工单保留状态。完整决策输入、业务轨迹和权重放在经授权的协作存储，公开仓提交源码、可共享技术知识和汇总。

规则组可以独立测试新算法。已训练权重配套使用原来的动作语义、映射与预算。拟让模型使用新动作时，先登记新目录，在留出工单对照收益，再由模型组与系统集成组决定是否补训。技术知识不改变原始 QoS 或实时写权限。
